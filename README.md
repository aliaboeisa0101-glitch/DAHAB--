# DAHAB — الإصدار 1.5

## شاشة تسجيل العامل
تمت إضافة شاشة مستقلة سريعة للعامل:
- العامل يدخل الكود فقط، مثل W-0001.
- تظهر أزرار حضور، انصراف، وإضافي.
- الوقت والتاريخ يسجلان تلقائياً.
- لا تظهر للعامل الرواتب أو السلف أو الخصومات أو أي تفاصيل مالية.
- بعد التسجيل يتم مسح الكود تلقائياً.
- شاشة الإدارة والتفاصيل تظل منفصلة للمدير.

يمكن فتح الشاشة من زر "شاشة تسجيل الحضور والانصراف" أو أيقونة اللمس في الرئيسية.

تشغيل:
flutter pub get
flutter run
